# OneJourney demo video

**Duration:** 43 seconds (under the 3-minute limit)
**Format:** silent, captioned product walkthrough using fictional challenge data.

| Scene | On-screen story |
| --- | --- |
| Overview | One connected path from first need to active service. |
| Discovery | Local Ollama advisor plus the model-free guided questionnaire. |
| Recommendation | Catalogue-backed bundle comparison with trade-offs visible. |
| Quote | Deterministic eligibility and itemized pricing. |
| Verification | Consent, local OCR and reviewable registry mismatches. |
| Tracker | Checkout prerequisites and the recorded order timeline. |
| Partner desk | Permission-based handoff and experimental synthetic propensity. |
| Cohort analytics | Segment and month filters for the synthetic acquisition funnel. |

No real customer records are shown. OCR verification is not presented as a completed pass in the video. The live local Qwen3 advisor was separately exercised; this machine took about 132 seconds to answer a synthetic scenario, so the always-available guided path is included for a slow or unavailable model.
